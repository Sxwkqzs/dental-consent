# 口腔治疗知情同意书 - 部署包

## 部署方法
1. 登录 github.com，进入 sxwkqzs.github.io 仓库
2. 上传 index.html 到仓库根目录（覆盖旧文件）
3. 等待 1-3 分钟自动部署
4. 访问 https://sxwkqzs.github.io/

## 修复内容（2026-10-05）
- 二维码从 PNG 改为 SVG 格式，兼容 iPhone 和 Android
- 其余逻辑完全保持 9月版本：Supabase 云端同步、访问码、轮询签字回传

## 使用流程
1. 医生端填写信息 → 保存到云端 → 生成二维码
2. 患者手机扫码 → 自动从云端加载数据 → 签字
3. 云端自动同步，医生端实时收到签字
